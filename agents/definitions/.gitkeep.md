# Agent Definitions

Esta carpeta contiene las definiciones JSON individuales de cada agent (opcional).

Por ahora, todos los agents están definidos en `/config/agent-config.json`.

## Uso Opcional

Si prefieres tener archivos separados por agent:

```
definitions/
├── angular-developer.json
├── architecture-agent.json
├── testing-agent.json
└── code-review-agent.json
```

Cada archivo seguiría este formato:

```json
{
  "id": "agent-id",
  "name": "Agent Name",
  "role": "role-name",
  "description": "Descripción del agent",
  "skills": ["skill1", "skill2"],
  "responsibilities": ["resp1", "resp2"],
  "constraints": ["constraint1", "constraint2"],
  "context": {
    "key": "value"
  }
}
```

## Configuración Actual

Actualmente, usa `/config/agent-config.json` para gestionar todos los agents en un solo lugar.
